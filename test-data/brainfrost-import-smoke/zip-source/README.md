# Projeto Aurora Data Platform

Este repositório reúne pipelines de ingestão, modelos analíticos e uma pequena
interface operacional. As decisões permanentes ficam em `docs/` e devem orientar
novos serviços da equipe.

Pull requests precisam informar o que mudou, como foi testado, riscos conhecidos
e instruções de rollback. Nenhuma alteração de produção é aprovada sem revisão de
outra pessoa.
