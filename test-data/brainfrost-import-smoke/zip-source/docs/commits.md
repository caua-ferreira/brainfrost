# Convenções de desenvolvimento

- Usar Conventional Commits: `tipo(escopo): descrição`.
- O escopo é opcional e deve representar a área afetada.
- A mensagem completa tem no máximo 150 caracteres.
- Não adicionar `Co-Authored-By` de Claude, Codex, Copilot ou outra IA.
- Comentários explicam regras de negócio complexas; não repetem o que o código já diz.
- Breaking changes precisam de nota de migração e versão nova do contrato.
