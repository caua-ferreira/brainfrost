# Operação e incidentes

Produção só muda com GMUD contendo responsável, janela, impacto, evidência de
teste e rollback. O rollback deve ser executável, não apenas uma frase genérica.

Depois de um incidente, registrar causa, sinal que permitiu detectar o problema,
ação corretiva e prevenção. Logs são estruturados e usam um código de correlação.
Nunca mostramos stack trace, endpoint interno ou resposta crua de fornecedor na
interface; o usuário recebe uma explicação simples e o código de suporte.
